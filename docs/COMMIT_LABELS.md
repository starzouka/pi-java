# Commit Labels Guide

Use these labels at the start of commit titles when possible:

- `[UI]`: screen, layout, navigation, controller, or UX behavior changes.
- `[EMAIL]`: SMTP, templates, notifications, sender rules, or email workflows.
- `[PDF]`: export formatting, generated documents, or PDF business logic.
- `[DB]`: schema/data access/query changes.
- `[FIX]`: bug fixes without a dedicated domain label.
- `[DOCS]`: documentation-only changes.

## Example Titles

- `[UI] improve admin team management interactions`
- `[EMAIL] refactor invitation template builder`
- `[PDF] adjust roster export spacing`
- `[FIX] prevent null pointer on tournament detail`
